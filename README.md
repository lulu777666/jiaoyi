# 合约手续费计算器

币安 U 本位合约（USDT / USDC）盈亏计算器，把开仓 + 平仓手续费都算进止盈、止损的盈亏里。

## 使用

- 选择保证金币种（USDT / USDC）和方向（做多 / 做空）
- 填写开仓价、数量（仓位价值，单位 USDT / USDC）、止盈价、止损价
- 止盈价下方显示含手续费的净盈利（绿色），止损价下方显示含手续费的净亏损（红色）
- 最下方可修改挂单 / 吃单费率，并选择开仓、平仓方式；改过的数字会自动记住

## 计算方式

- 手续费 = 成交金额 × 费率，开仓、平仓各收一次
- 盈亏 = （平仓价 − 开仓价）× 币数（做空取反）− 手续费
- 币数 = 数量 ÷ 开仓价

默认费率为币安普通用户（VIP0）：USDT 挂单 0.02% / 吃单 0.05%，USDC 挂单 0% / 吃单 0.04%（USDC 为活动价）。以账户「手续费等级」页面为准。
